# Đồ Án Chuyên Ngành: Hệ Thống Báo Cáo Sự Cố Cơ Sở Vật Chất TVU

## 1. Thông Tin Sinh Viên
* **Họ và tên:** Nguyễn Như Ngọc
* **Mã số sinh viên:** (Nhập MSSV của bạn)
* **Lớp:** DA23TTA
* **Giảng viên hướng dẫn:** (Nhập tên GVHD)

## 2. Mô Tả Đề Tài
Xây dựng ứng dụng di động hỗ trợ sinh viên, giảng viên và viên chức phát hiện, báo cáo và theo dõi quá trình xử lý các sự cố cơ sở vật chất trong khuôn viên Trường Đại học Trà Vinh.

## 3. Công Nghệ Sử Dụng (Tech Stack)
* **Mobile App:** Flutter (hoặc React Native)
* **Backend API:** Laravel (hoặc ASP.NET / FastAPI)
* **Database:** MySQL
* **Dịch vụ khác:** Firebase Cloud Messaging (Push Notification)

## 4. Cấu Trúc Thư Mục
* `/mobile-app`: Mã nguồn ứng dụng di động.
* `/backend-api`: Mã nguồn máy chủ và cơ sở dữ liệu.
* `/progress-report`: Nơi lưu trữ các file báo cáo tiến độ hàng tuần.
